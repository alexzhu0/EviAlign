# ActLumen · 明行品牌与范围说明

品牌更新日期：2026-10-26。用户已选定 ActLumen · 明行为整个项目的新名称。

## 名称与一句话定义

| 用途 | 统一表达 |
| --- | --- |
| 英文项目名 | ActLumen |
| 中文项目名 | 明行 |
| 中英文组合 | ActLumen · 明行 |
| 业务定位 | 企业 AI 行动质检助手 |
| 主张 | 让 AI 行动清晰，让业务协作高效。 |
| 工程定位 | Pre-execution evidence for reviewable AI actions in enterprise workflows. |

Act 表示行动，Lumen 借“光”的意象表达清晰与可理解。“明行”强调把 AI 准备采取的行动及其依据看清楚，让员工参与判断，让团队能够复盘。

ActLumen 为企业智能体提供执行前行动依据核对；配合独立业务沙箱中的意图观察，为人工判断提供提示与可复查的检查记录。企业既有系统继续拥有身份、权限、审批语义和实际执行的职责。

## 业务读者与工程读者

面向业务与评审，先讲问题、场景、提效路径、企业收益和试点办法。推荐使用“行动依据核对”“意图偏差提示”“需要人工判断”“检查记录”等表达。

面向工程，继续使用准确的证据契约与执行前控制平面定义。意图判断不是身份验证或授权；依据匹配不代表材料内容真实、业务规则正确或行动获批。`allow_candidate` 仅表示候选证据，当前证据与观察面保留 `result_status: not_executed`。

## 兼容名称

AgentHarness 是本项目的历史技术名称。当前品牌更新保留以下工程标识，以兼容既有使用与历史证据：

- `./agentharness` 命令、Python 包/安装名 `agentharness` 和 `src/agentharness/`。
- 既有协议名、JSON 字段、CLI 输出、示例与测试。
- 已有文档文件名、历史发布与交接记录，以及单独维护的外部仓库名称。
- 当前 `v0.2.0-alpha.1` / `0.2.0a1` 版本；本次改名不构成新版本发布。

当前入口和新材料使用 ActLumen · 明行；历史记录按其发生时的名称保留。GitHub 仓库名称按用户本次单独确认同步为 ActLumen，实际结果以维护记录中的回执为准。品牌选择不表示已经完成商标或域名可用性确认。
