# EviAlign 品牌与能力范围

更新日期：2026-10-30。用户选定项目名称 **EviAlign**，英文优先；不指定新的中文品牌名称。历史名称为 AgentHarness 与 ActLumen · 明行。

## 项目目的与当前阶段

EviAlign 是面向企业行动型智能体的前沿研究：探索 AI 做事前如何接受业务审核、如何保留行动与判断依据，以及如何通过积累人工判断和最终结果，研究哪些环节需要人、哪些环节有条件减少人工介入。

“签字与审核”描述业务愿景。当前主仓库实现执行前依据核对基础，独立沙箱提供意图观察实验；真实业务确认接入、完整记录积累与人工参与调整仍待建设。可信签名和最终审批执行继续由外部系统负责。详见[项目目的与当前进展](project-purpose-and-progress.zh-CN.md)及[英文版](project-purpose-and-progress.md)。

## 定位

| 用途 | 表达 |
| --- | --- |
| 项目名称 | EviAlign |
| 名称含义 | Evidence（依据）与 Align（对齐）：让行动请求与对应依据有清楚的联系。 |
| 研究目的 | 为未来 AI 参与业务行动研究审核与复盘机制，积累人机分工调整所需的证据。 |
| 工程定位 | Pre-execution evidence checks for AI action requests. |
| 当前阶段 | 部分基础原型与独立合成观察实验；完整业务审核与经验积累闭环尚未实现。 |
| 业务切口 | 从交付异常的跨团队协同设想切入，研究行动与可信确认的对应及相对现有机制的增量。 |

现有 API、细粒度授权和审批机制可能已满足业务需要。EviAlign 的企业价值取决于实际缺口、现有机制的补强成本及跨智能体复用效果，均需要验证。

## 已有基础与未来工作

| 范围 | 状态 |
| --- | --- |
| 在受信请求与证据前提下检查当前请求和证据是否对应，输出确定性检查记录 | 已实现于本仓库。 |
| 检查请求发生变化后继续使用旧证据 | 已实现于对应证据契约，结果仍为未执行。 |
| 意图可能偏离原需求时给出观察提示 | 可选 Jev 观察已实现于独立本地业务沙箱，不在本仓库 CLI 中调用。 |
| 真实审批源接入、审批字段与行动字段的业务对照、集中核对界面 | 拟议设计与验证。当前业务证据接口绑定审批字段，但不解释其业务含义或验证审批有效性。 |
| 人工确认、修改理由、后续业务结果的完整积累 | 下一阶段研究，尚未形成业务闭环。 |
| 依据积累结果调整人工参与 | 尚未实现；需独立验证、企业批准、限定范围和持续复核，不能用历史通过率或模型分数直接决定。 |
| 身份、授权、签字、审批语义、事务和实际执行 | 由外部系统负责；本仓库不授予或执行。 |
| 处理时间、返工、成本和 ROI 改善 | 预期收益，尚未通过真实业务试点实测。 |

`allow_candidate` 仅表示候选证据；当前证据与观察输出保留 `result_status: not_executed`。请求和证据若均被替换并重新计算，本仓库的无密钥摘要不能独立证明其来源真实。

2026-10-21 的 84 例评测来自独立沙箱的合成意图观察，非人工真值或联想业务数据，不能证明真实审批字段对照或生产准确率。[完整评测记录](33-jev-shadow-maintenance-handoff.md)
